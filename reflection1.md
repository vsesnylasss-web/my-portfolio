Exercise 1 - Reflection Questions

1. Why did the conflict occur?

The conflict occurred because both branches changed the same lines in the Skills section of portfolio.md.

2. What would have prevented this conflict?

Better coordination and updating branches before making changes could have prevented the conflict.

3. How do you avoid conflicts when working on multiple devices?

I use git pull before starting work, commit changes regularly, and git push after finishing.

4. What was the most challenging part of resolving the conflict?

The most challenging part was combining both versions without losing any information.

5. How did Git help you identify where the conflict was?

Git showed conflict markers in the file, helping me identify the conflicting changes.
